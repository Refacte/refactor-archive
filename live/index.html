Try a change of representation: a recurrence

Choose a weighted difference and remove the remaining interaction.

A working example

Choose what moves.

Start with sn+1 = sn + sn−1. Try un = sn − c sn−1.

un+1 = (1 − c)un + (1 + c − c²)sn−1
unmultiply by 1 − c→un+1
sn−1remaining input ↗

At c = 1, the extra input remains. The ordinary difference has not separated the recurrence.

A useful test: does the new description retain the operation?

Compare the identity with the shear J(x, y) = (x + y, y). Both have eigenvalues 1, 1. Iterating the shear gives Jⁿ(0, 1) = (n, 1), whereas the identity leaves (0, 1) fixed.

The eigenvalue list cannot calculate this difference. Retaining the off-diagonal action can.
